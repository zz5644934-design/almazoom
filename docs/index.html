AlmaZoom — 1000× zoom for Samsung Camera

A Vector / LSPosed module that extends the zoom slider of the stock Samsung Camera up to 1000× digital zoom in rear Photo mode.

Download APK Source on GitHub
Please note: this is a digital crop. The module enlarges the center of the preview and crops the processed JPEG, it does not add optical detail. It needs root and Vector. Tested on the Galaxy S25 Ultra with Samsung Camera 17.0.00.43 only.

What it does

  • Zoom up to 1000× inside the stock camera, with a magnifier button in the camera quick settings.
  • Restores your last zoom when the camera is opened again.
  • Crops the JPEG and the draft that the gallery shows, so there is no jump in the framing.
  • Shows a spoiler animation in the gallery while a photo is still being processed.
  • Compact zoom labels on the buttons (for example 538×).

Install

  1. You need a rooted phone with Vector already set up.
  2. Download the APK from the latest release and install it. If a module with another signature is installed, uninstall it first.
  3. In Vector enable AlmaZoom for com.sec.android.app.camera. For the gallery spoiler also enable it for com.sec.android.gallery3d.
  4. Turn off HEIF and Motion Photo in the camera settings, fully close the camera and open it again, then tap the magnifier.

Compatibility

Galaxy S25 Ultra (SM-S938U1), One UI 9, Samsung Camera 17.0.00.43: checked. Other models and camera versions: untested, reports are welcome in GitHub issues. An older build for One UI 8.0 (Camera 16.0.00.66) and a Xiaomi Camera beta are on the releases page.

По-русски

AlmaZoom — модуль Vector/LSPosed, который расширяет зум штатной камеры Samsung до 1000× цифрового зума в режиме «Фото» задней камеры.

Важно: это цифровой кроп, оптического улучшения деталей нет. Нужен root и Vector. Проверено только на Galaxy S25 Ultra, Samsung Camera 17.0.00.43.

  1. Скачай APK в последнем релизе и установи как обычное приложение.
  2. В Vector включи AlmaZoom для камеры Samsung (com.sec.android.app.camera), для спойлера ещё и для галереи (com.sec.android.gallery3d).
  3. Выключи HEIF и «Фото в движении», полностью закрой камеру, открой заново и нажми лупу в быстрых настройках.
