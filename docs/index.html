AlmaZoom

Extend the Samsung Camera zoom slider up to 1000×. A Vector / LSPosed module, also known as AlmaLens.

Download AlmaLens 0.15.1 (One UI 9) GitHub

How it works

Samsung Camera shoots and processes the photo at its own maximum zoom. AlmaZoom enlarges the preview and crops the processed JPEG around the same center before it reaches Gallery. This is digital zoom (a crop), not optics: expect more detail than the stock limit allows only where the sensor resolved it. Output is capped at 2048 px on the longest edge.

Requirements

Rooted Android device with Vector set up. Rear camera, Photo mode, JPEG (HEIF off).

Install

  1. Install the APK.
  2. Enable it in Vector, scope: Samsung Camera (com.sec.android.app.camera).
  3. Fully close and reopen Camera.
  4. Scroll the zoom slider past the stock limit.
