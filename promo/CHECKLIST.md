# Чек-лист продвижения AlmaZoom

## 1. GitHub Pages
- [ ] Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/docs` → Save.
- [ ] Через минуту открой https://zz5644934-design.github.io/almazoom/ и проверь, что страница грузится.

## 2. Описание и теги репозитория
- [ ] About (шестерёнка справа на главной) → Description: `AlmaZoom: 1000x digital zoom for the Samsung Camera (One UI 8 / 9, Galaxy S25 Ultra). Xposed module for Vector / LSPosed.`
- [ ] Website: https://zz5644934-design.github.io/almazoom/
- [ ] Topics: `almazoom`, `samsung-camera`, `galaxy-s25-ultra`, `one-ui`, `xposed-module`, `lsposed`, `vector`, `digital-zoom`, `1000x-zoom`, `android`
- [ ] Релиз: актуальный APK в последнем релизе (его открывает кнопка Download на странице).

## 3. Google Search Console
- [ ] https://search.google.com/search-console → Add property → URL prefix → `https://zz5644934-design.github.io/almazoom/`
- [ ] Подтверди владение: HTML-тег (добавь `<meta name="google-site-verification" ...>` в `<head>` файла `docs/index.html`) или файл подтверждения в `docs/`.
- [ ] URL Inspection → вставь адрес страницы → Request indexing.

## 4. Bing Webmaster
- [ ] https://www.bing.com/webmasters → Add site → Import from Google Search Console (самый простой способ) или подтверди через мета-тег.
- [ ] URL Submission → отправь адрес страницы.

## 5. Посты (см. `reddit-en.md`, `4pda-xda-ru.md`)
- [ ] Запиши короткое видео: зум 500x+, спойлер в галерее.
- [ ] 4PDA и Telegram-чаты по Samsung / LSPosed: первыми, по отзывам поправь README.
- [ ] Reddit: r/GalaxyS25Ultra, r/LSPosed, один-два сабреддита в день.
- [ ] XDA: форум Galaxy S25 Ultra.
- [ ] Ссылку на репозиторий положи в профиль GitHub и в био Telegram/YouTube.

Индексация новой страницы занимает от нескольких дней до пары недель. Ссылки на страницу с других сайтов (посты, профили) ускоряют её.
