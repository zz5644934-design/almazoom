# AlmaLens 0.14

Модуль Vector/LSPosed для Galaxy S25 Ultra на One UI 9 с Samsung Camera **17.0.00.43** (код версии **1700043000**). Проект объединяет эффекты AlmaLens 0.13 и логику зума AlmaZoom 1.1.3 beta 6.

В режиме «Фото» задней камеры работают стекло и блик на шкале, цветное кольцо фокуса и расширенный цифровой зум до 1000×. Цифровой зум рассчитан на JPEG обычного разрешения. Для него выключи HEIF и «Фото в движении». После штатного максимума модуль увеличивает центр превью и кадрирует обработанный JPEG перед публикацией. Режим высокого FPS остаётся экспериментальным и по умолчанию выключен.

## Установка

1. Установи APK поверх прежнего AlmaLens. В менеджере модулей включи AlmaLens только для `com.sec.android.app.camera`.
2. Выключи отдельный модуль AlmaZoom для камеры, чтобы оба модуля не обрабатывали один снимок.
3. Полностью закрой Samsung Camera и открой заново. В быстрых настройках камеры нажми значок лупы, чтобы переключить цифровой зум. Удерживай лупу, чтобы открыть настройки AlmaLens и включить экспериментальный FPS.

## Сборка

Нужны JDK 17, Android SDK 35 и доступ к репозиториям зависимостей Gradle. На Linux и macOS выполни `./gradlew :app:assembleDebug`, на Windows — `gradlew.bat :app:assembleDebug`. APK появится в `app/build/outputs/apk/debug/`. Для установки собранного APK поверх уже установленного AlmaLens нужна совпадающая подпись.

Сборка и подпись скачиваемого APK проверены. Превью, эффекты и сохранённые фото объединённого модуля ещё нужно проверить на телефоне.
