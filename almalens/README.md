# AlmaZoom 0.16.0

Модуль Vector/LSPosed для Galaxy S25 Ultra на One UI 9 с Samsung Camera **17.0.00.43** (код версии **1700043000**). Только зум: цифровой зум до 1000× в режиме «Фото» задней камеры.

Это цифровой кроп: модуль увеличивает центр превью и обрезает обработанный JPEG, оптического улучшения деталей он не даёт. Для него выключи HEIF и «Фото в движении».

В 0.16.0 осталось: зум до 1000×, лупа в быстрых настройках камеры, восстановление зума, кроп JPEG и черновика в галерее, спойлер в галерее, пока фото обрабатывается, подписи зума на кнопках. Убрано: жидкое стекло и блик на шкале, цветное кольцо фокуса, 60 fps превью.

## Установка

1. Нужны root и Vector. Установи APK как обычное приложение. Если стоял модуль с другой подписью, сначала удали его.
2. В Vector включи AlmaZoom для `com.sec.android.app.camera`. Для спойлера включи его ещё для `com.sec.android.gallery3d`.
3. Выключи отдельный модуль AlmaZoom из корня репозитория, чтобы оба не обрабатывали один снимок.
4. Полностью закрой камеру и открой заново. В быстрых настройках камеры нажми лупу, чтобы включить расширенный зум.

## Сборка

JDK 17, Android SDK 35. `./gradlew :app:assembleDebug` (Windows: `gradlew.bat :app:assembleDebug`), APK в `app/build/outputs/apk/debug/`.

Проверено только на Galaxy S25 Ultra, Camera 17.0.00.43.
